影之刃零 · 道具名称与距离提示 MOD v1.9.0 完整包（模组版本 1.9.0）

本包包含道具提示模组和 PBZ 专用 UE4SS 加载器，无需另下加载器或先安装旧版。
游戏可以安装在任意盘符，安装无需修改游戏存档。

默认开启道具名称与距离提示，记忆之花提示也默认开启；路线默认关闭。
v1.9.0 修正部分容器名称中混入旧条目的问题，新增“未激活铃铛”筛选；保留书名页号显示与原有按键。
旧版的各功能快捷键不再使用。设置只影响本次运行，安装或升级后下次启动游戏生效。

一、首次安装（尚未安装 UE4SS）

1. 完全退出游戏，把本压缩包解压到一个普通文件夹。
2. 在 Steam 游戏库中右键“影之刃零” → 管理 → 浏览本地文件。
   打开的 PBZ 文件夹就是游戏根目录，里面已有 platform 文件夹。
3. 把本包中的整个 platform 文件夹复制到游戏根目录，与原有 platform 合并。
   本包已配置好自动启用，不需要手动编辑文件。
   如果目标位置已有 dwmapi.dll 或 ue4ss 文件夹，请先看第二节，避免覆盖其他模组设置。
4. 从 Steam 正常启动游戏并载入存档，道具提示会自动启用。

安装后应存在以下文件（不要多套一层完整包或 platform 文件夹）：
  你的PBZ游戏目录\platform\steam\dwmapi.dll
  你的PBZ游戏目录\platform\steam\ue4ss\UE4SS.dll
  你的PBZ游戏目录\platform\steam\ue4ss\Mods\PBZItemBeacon\Scripts\main.lua
  你的PBZ游戏目录\platform\steam\ue4ss\Mods\PBZItemBeacon\enabled.txt

安装到 PBZ\platform\steam 这一层；不要放到 PBZ\steam 或 ProjectPBZ\Binaries\Win64。
本包不含 PBZ.exe，也不需要替换游戏程序、version.dll 或帧生成补丁。

二、已经安装过 UE4SS 或旧版道具提示

v1.2 至 v1.8.2 用户可以直接升级到 v1.9.0，无需依次安装中间版本。
如果已经使用本包同一款 PBZ 适配版 UE4SS（v3.0.1-1195-g1ceefac8）：
1. 退出游戏，备份现有 PBZItemBeacon 文件夹，记录自己改过的 config.lua 设置。
   备份必须放在 Mods 文件夹之外，避免旧版也被加载。
2. 只把本包 platform\steam\ue4ss\Mods\PBZItemBeacon 文件夹复制到游戏的对应位置。
   复制会覆盖 config.lua；完成后可参照备份，在新版配置中恢复自己的字号、颜色等设置。
   请复制整个 PBZItemBeacon 文件夹，并保留新版配置中的各项设置，不要只替换 main.lua。
3. 打开游戏中的 platform\steam\ue4ss\Mods\mods.txt，保留其他行，加入：
   PBZItemBeacon : 1
   如果已经有这一行，只把末尾数字设为 1，不要重复添加。
4. 确认 ue4ss\Mods\shared\UEHelpers\UEHelpers.lua 存在；缺少时从本包补入。

这一分支不需要复制整个 platform，也不需要覆盖自己的 mods.txt、mods.json、
UE4SS-settings.ini、加载器 DLL 或现有共享脚本。
如果已有加载器的来源/版本不同，先备份原件并核实与本包的兼容性；
不同加载器和其他模组的组合尚未逐一验证，不能直接按首次安装步骤全覆盖。

三、统一面板操作

F5：打开 / 关闭统一面板。在任何子页按 F5 都直接关闭，重新打开回到主面板第 1 行。
PgUp / PgDn：选择上一行 / 下一行，即键盘上的 PageUp / PageDown。
Enter：调整当前设置或确认当前操作。

面板只在打开时显示；面板关闭时，翻页键和 Enter 不执行本模组的面板操作。
全部提示关闭后，仍可用 F5 打开面板，把“全部提示”重新设为开启。
采用翻页键选择，避免角色跟着移动。
设置面板打开时暂时隐藏场景中的道具标签；选择物品页只显示当前选中目标的预览标签。
关闭面板后恢复原有标签显示规则，原锁定目标和路线设置保留。

主面板项目

选择物品：进入“选择物品”子页。选中物品后按 Enter 锁定目标并收起面板；
  子页第一行“返回设置”可回主面板。如果全部提示已关闭，此操作会把选中行
  移到“全部提示”，不会自动开启；请先按 Enter 手动开启，再选择物品。
地面路线：开启 / 关闭目标的地面光点路线，默认关闭；有锁定目标后才会显示路线。
取消当前目标：取消手动锁定，移除目标面板和光点，不自动改选其他物品。
全部提示：开启 / 关闭道具显示。关闭会取消锁定目标、隐藏道具和路线，设置面板仍可操作。
物品类型：依次为全部、隐藏纯钱、养成道具、宝箱、钱、书籍收藏、记忆之花、碎片、未激活铃铛，再回全部。
提示范围：默认 120 米，依次切换为 240 米、60 米、120 米。
显示数量：默认最多 24 个，可切换为最近 3 个或最近 1 个。
高差提示：默认关闭，控制普通悬浮标签是否显示高差；列表和目标面板始终显示明显高差。
记忆之花：默认开启；关闭时筛除普通候选中的记忆之花、记忆花瓣及含花的混合掉落，已锁定目标保留。
导航时只显示目标：默认开启；路线开启且目标有效时隐藏其他标签，可独立关闭。

各设置不自动保存。关闭面板、取消目标或关闭全部提示，都不会改写本次的“地面路线”选项。
再次选择目标时沿用本次的“地面路线”选项；重新启动游戏则恢复 config.lua 中的默认值。

选定目标与步行参考（实验功能）

第一次使用：按 F5，选择“选择物品”并按 Enter，再用 PgUp / PgDn 选目标，按 Enter 锁定。
需要路线时，再打开面板把“地面路线”设为开启，按 F5 收起面板。
取消目标请在主面板选择“取消当前目标”；单纯收起面板不会取消目标。

物品子页显示附近目标的名称摘要、距离和高差。候选按物品类型、提示范围和记忆之花设置筛选，
不会因“显示数量”选了最近 1 个或最近 3 个而只剩这些对象。
已经锁定的目标不随物品类型、提示范围、显示数量或记忆之花开关改变。
手动取消目标、关闭全部提示、目标失效或切换游戏世界时，才会取消锁定。
打开游戏菜单时隐藏模组面板及路线，锁定目标可保留；返回游玩后可重新按 F5 打开设置。

短蓝色光点只展示角色附近的一小段路径。出现“后续路线未确认”时，表示只找到部分路径，
不能据此确认全程可达。地面光点只供普通步行导航参考，不保证未探索或未加载区域、
跳跃、攀爬、锁门或机关处可通行。关闭路线后恢复原有普通标签显示规则。

四、显示与默认配置

未激活铃铛

在“物品类型”中选择“未激活铃铛”，只查看当前已加载、范围内且状态明确未激活的传送／休息铃铛。
“全部”和“隐藏纯钱”也会保留这些铃铛；书籍、碎片等其他专门类型不会混入铃铛。
标签显示“未激活铃铛·地点名”；地点名称尚未取得时只显示“未激活铃铛”。
状态未知时暂不显示，已激活但暂时禁止传送的铃铛不会被当成未激活。
同一铃铛编号的重复装饰不重复列出；铃铛与道具一样支持距离、高差和手动锁定。
锁定的铃铛被激活或失效后会取消目标。模组仅作提示，不会自动激活铃铛、休息或传送。

碎片筛选

在“物品类型”中选择“碎片”，可同时查找黑石碎片和杀气琥珀碎片。
普通黑石、普通杀气琥珀及其他种类的碎片不属于这个选项；养成道具类型仍包含这两种碎片。
碎片类型与当前提示范围、记忆之花开关同时生效；含碎片的混合掉落保留名称摘要，
仅为可能掉落的目标继续标为“可能”。切换类型不会取消已经锁定的目标。

名称数据未齐且列表为空时显示“名称数据尚未就绪，请稍后再试”，不能解释为附近没有目标。
已有明确碎片编号但名称未取得的条目仍显示“名称待识别”。
无匹配目标时显示“当前已加载范围内未发现符合筛选的目标”，这不代表全地图已经找完。

类型筛选和显示规则

“全部”关闭类型筛选。
“隐藏纯钱”只隐藏已确定仅含钱的散落物；宝箱、混合掉落、未知和“可能”目标保留。
“养成道具”和“钱”显示包含对应类型的目标，也保留未知类别和“可能”目标，避免误漏。
“宝箱”只显示宝箱。
“书籍收藏”只显示已识别的书籍、书页或信件；混合掉落只要含其中一种就保留完整标签，
“可能”目标只有包含上述类型时保留，并继续标注“可能”。仅有未知类别的目标不混入此模式。
“物品类型”中的“记忆之花”显示花和花瓣；主面板的“记忆之花”开关关闭时，此类型的普通候选不显示。

“记忆之花”关闭时，普通候选中含花 / 花瓣的混合掉落会整处隐藏，其他候选不受影响。
已锁定目标保留，即使它包含花或花瓣。
记忆之花只提示当前已加载、提示距离内、未完成且可交互的目标。
这些筛选只便于查找当前范围内的目标，不提供全地图收集完成度或缺页总表。

黄色文字表示普通道具，青色文字表示宝箱；标签优先显示游戏当前语言的具体名称。
短标签由名称摘要、必要时的“可能：”、距离及高差组成，不附类型或“宝箱”文字前缀。
黑石碎片、杀气琥珀碎片排在其他名称之前；每处最多显示两个名称，其余用“另N种”概括。
过长的名称会省略，距离和已开启的高差信息保留。
未获得具体名称的项目标为“名称待识别”，不把未知名称猜成某种碎片。
优先使用已经确定的生成内容；没有生成内容时才参考可能掉落，并将这些候选内容全部标为“可能”。
“可能”不保证本次实际获得。
距离是三维直线距离，不是行走路线长度；标签可穿过遮挡，背后目标需转动视角查看。
普通悬浮标签的高差开启后，绝对高度差达到 2 米才显示 ↑ / ↓；例如 ↑8 m 表示目标在角色上方约 8 米，
不代表楼层编号，也不保证有直接通行的路线。
只显示游戏已经加载的可拾取目标；调大范围不会强制加载远处地图。
模组不主动领取物品、激活铃铛、传送、修改背包或写入游戏存档。

设置默认值和字号

退出游戏后编辑：
  你的PBZ游戏目录\platform\steam\ue4ss\Mods\PBZItemBeacon\Scripts\config.lua

Enabled = true：默认开启全部提示；设为 false 后仍可从 F5 面板重新开启。
RouteEnabled = false：默认关闭路线；true 表示开启，仍需要手动选定目标。
RouteOnlyTarget = true：默认导航时只显示目标；false 同时保留普通标签。
DefaultFilterIndex = 1：1 全部；2 隐藏纯钱；3 养成道具；4 宝箱；5 钱；6 书籍收藏；7 记忆之花；8 碎片；9 未激活铃铛。
DefaultRangeIndex = 2：默认第二档 120 米；RangesMeters = {60, 120, 240} 为三档范围。
DefaultFocusIndex = 1：1 最多 24 个；2 最近 3 个；3 最近 1 个。
ShowHeightDifference = false：默认关闭普通悬浮标签的高差；true 开启，不影响列表和目标面板。
HeightDifferenceMinMeters = 2：显示高差箭头的最小高度差。
ShowMemoryFlowers = true：默认开启花提示；false 筛除含花或花瓣的普通候选，不取消已锁定目标。
FontScale = 1.6：仅调整物品标签字号，不改变面板或光点的默认比例。

修改后重启生效。请保留新版配置中的其他项目；面板中的调整不会写回配置文件。

停用 / 卸载

临时停用：按 F5，在面板中关闭“全部提示”；需要恢复时仍从 F5 面板开启。
持续停用：退出游戏，将 config.lua 的 Enabled = true 改为 Enabled = false。
卸载：退出游戏，移走 PBZItemBeacon 文件夹，并移除 mods.txt 中本模组自己的那一行。
其他模组使用的 UE4SS 加载器可以保留。

回退旧版：退出游戏，把当前 PBZItemBeacon 移到 Mods 文件夹之外，再将此前备份的整个旧版
PBZItemBeacon 放回原位置，并保留 mods.txt 的其他模组条目。不要混用不同版本的 Lua 文件。
只恢复对应旧版配置，不改存档；本次运行的面板设置不会自动保存到备份。
