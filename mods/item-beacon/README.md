# 道具名称与距离提示 · PBZItemBeacon

版本 **1.9.0** ｜ 适用 Windows Steam 版影之刃零 ｜ 需要 PBZ 适配版 UE4SS `v3.0.1-1195-g1ceefac8`

在当前**已经加载**的范围内，给可拾取目标加悬浮标签：名称、直线距离、可选高差。按 F5 打开设置面板，可以按类型筛选、切换范围、锁定一个目标并显示地面光点路线。

只读为主：不主动领取物品、不激活铃铛、不传送、不改背包、不写存档；唯一的运行时改动是临时叠加的界面绘制。

## 安装

### A. 全新安装（还没有 UE4SS）

用 Releases 里的 `PBZItemBeacon-1.9.0-full.zip`（自带加载器）：

1. 完全退出游戏，解压到普通文件夹。
2. Steam 库右键游戏 → 管理 → 浏览本地文件，进入游戏根目录。
3. 把包内整个 `platform` 文件夹复制进去，与原有 `platform` 合并。
4. 启动游戏载入存档即可生效。

包内 `mods.txt` 默认只启用本模组；`UE4SS-settings.ini`、加载器 DLL、共享 `UEHelpers.lua` 均为原样。

### B. 已有同一款 PBZ 适配版 UE4SS

只把本目录的 `PBZItemBeacon` 文件夹复制到 `<游戏目录>\platform\steam\ue4ss\Mods\`，然后：

1. 备份现有 `PBZItemBeacon`（放到 `Mods\` 之外，避免旧版被加载），记下自己改过的 `config.lua`。
2. `mods.txt` 保留其它行，确保有 `PBZItemBeacon : 1`；已有该行就只把末尾数字改成 `1`，不要重复添加。
3. 确认 `Mods\shared\UEHelpers\UEHelpers.lua` 存在。

升级时请复制整个文件夹而不是只替换 `main.lua`；新版 `config.lua` 会覆盖旧配置，复制完再照备份恢复字号、颜色等设置。

## 按键

| 按键 | 作用 |
| --- | --- |
| `F5` | 打开 / 关闭面板；任何子页按 F5 直接关闭，重开回到主面板第 1 行 |
| `PgUp` / `PgDn` | 上一行 / 下一行（键盘 PageUp / PageDown） |
| `Enter` | 调整当前设置 / 确认当前操作 |

面板关闭时，翻页键和 Enter 不触发本模组的操作；打开游戏原生菜单时面板与路线隐藏，锁定目标可以保留。

## 面板项目

| 项目 | 说明 |
| --- | --- |
| 选择物品 | 进入物品子页，用 PgUp/PgDn 选目标、Enter 锁定并收起面板；子页第一行「返回设置」回主面板 |
| 地面路线 | 开关锁定目标的地面光点路线，默认关闭；只作步行参考（实验功能） |
| 取消当前目标 | 取消手动锁定，移除目标面板和光点，不自动改选其它物品 |
| 全部提示 | 开关所有道具显示；关闭会取消锁定目标，面板本身仍可操作 |
| 物品类型 | 全部 / 隐藏纯钱 / 养成道具 / 宝箱 / 钱 / 书籍收藏 / 记忆之花 / 碎片 / 未激活铃铛 |
| 提示范围 | 120 米（默认）/ 240 米 / 60 米 循环 |
| 显示数量 | 最多 24 个（默认）/ 最近 3 个 / 最近 1 个 |
| 高差提示 | 普通悬浮标签是否显示 ↑ / ↓，默认关闭；列表与锁定面板始终显示 |
| 记忆之花 | 默认开启；关闭后普通候选中的花、花瓣及含花混合掉落整处隐藏，已锁定目标保留 |
| 导航时只显示目标 | 默认开启；路线开启且目标有效时隐藏其它标签 |

面板里的改动不自动保存：关闭游戏后回到 `config.lua` 的默认值。

## 配置项

退出游戏后编辑 `PBZItemBeacon\Scripts\config.lua`，重启生效。

| 字段 | 默认 | 含义 |
| --- | --- | --- |
| `Enabled` | `true` | 默认开启全部提示；设 `false` 后仍可从 F5 面板开启 |
| `RangesMeters` | `{60, 120, 240}` | 三档提示范围（米） |
| `DefaultRangeIndex` | `2` | 默认档位，对应 120 米 |
| `MaxMarkers` | `24` | 「显示数量」第一档的最大标签数 |
| `DefaultFilterIndex` | `1` | 1 全部、2 隐藏纯钱、3 养成道具、4 宝箱、5 钱、6 书籍收藏、7 记忆之花、8 碎片、9 未激活铃铛 |
| `DefaultFocusIndex` | `1` | 1 最多 24 个、2 最近 3 个、3 最近 1 个 |
| `ShowMemoryFlowers` | `true` | 花提示开关的默认值 |
| `ShowHeightDifference` | `false` | 普通标签是否显示高差 |
| `HeightDifferenceMinMeters` | `2` | 显示高差箭头的最小高度差 |
| `RouteEnabled` | `false` | 路线默认开关（仍需手动选目标） |
| `RouteOnlyTarget` | `true` | 导航时是否只显示目标 |
| `FontScale` | `1.6` | 只调整物品标签字号 |
| `HeightOffsetCm` | `100` | 标签相对目标的高度偏移 |
| `ItemColor` / `ChestColor` | 黄 / 青 | 普通道具与宝箱的文字颜色 |

## 显示规则要点

- 黄色文字 = 普通道具，青色文字 = 宝箱；名称优先取游戏当前语言的具体名称。
- 书页显示为「《书名》第N页」（N 是游戏数据里的书内顺序，未集齐也能显示）；关系不明确时保留原标题。
- 黑石碎片、杀气琥珀碎片排在其它名称之前；每处最多显示两个名称，其余用「另N种」概括。
- 来源含不确定掉落时整条标为「可能」，不保证本次实际获得。
- 距离是三维直线距离，不是行走路线长度；标签可穿过遮挡，背后的目标要转视角才能看到。
- 只显示游戏已经加载的目标；调大范围不会强制加载远处地图。列表为空只说明当前范围没有符合筛选的目标，不代表全地图找完。

## 未激活铃铛

「物品类型」里的「未激活铃铛」只列出当前已加载、范围内、状态明确未激活的传送 / 休息铃铛，显示为「未激活铃铛·地点名」。状态未知时暂不显示；已激活但暂时禁用传送的不会被当成未激活。锁定的铃铛被激活或失效后自动取消目标。模组不会替你敲铃、休息或传送。

## 停用与卸载

- 临时停用：F5 面板里关「全部提示」，或把 `Enabled` 设为 `false`。
- 卸载：退出游戏，移走 `PBZItemBeacon` 文件夹，并删掉 `mods.txt` 里本模组那一行。其它模组用的 UE4SS 可以保留。
- 回退旧版：退出游戏，把当前 `PBZItemBeacon` 移到 `Mods\` 之外，放回备份的整个旧版文件夹；不要混用不同版本的 Lua 文件。不改存档，本次面板设置也不会写进备份。

## 模块说明

| 文件 | 职责 |
| --- | --- |
| `main.lua` | 扫描、候选排序、标签生成、F5 面板与选择列表 |
| `categories.lua` | 读取道具图鉴与名称表，做分类和名称摘要 |
| `bells.lua` | 只读取铃铛状态与地点名 |
| `navigation.lua` | 单个锁定目标的短路径查询，只缓存坐标 |
| `overlay.lua` | 屏幕空间文字与世界空间光点绘制 |
| `chinese_font.lua` | 复用游戏运行时中文字体 |
| `config.lua` | 默认配置 |
